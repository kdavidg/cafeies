# PRÁCTICA RA7 CAFETERIA (FRONT-END)
Hecho por Mario Sánchez y Kleiner David Gonzaga 1º DAWINT

## Características

- **Login con Google**: Autenticación mediante OAuth
- **Carrito de compras**: Agregar/quitar productos
- **Favoritos**: Sistema de favoritos sincronizado con BD
- **Franjas horarias**: Selección dinámica de horarios de recogida
- **Panel admin**: Gestión de pedidos y productos
- **Historial**: Ver pedidos anteriores
- **Responsive**: Diseño adaptable a móvil, tablet y desktop
- **Buscador**: Filtrar productos por nombre
